# linux-admin-lab

Main goal of this project is to learn by practice learn how to administer Linux servers

# Technologies to learn:
- Linux administration
- networking
- troubleshooting
- security
- automation

# Environment
- Windows 11 host
- Ubuntu Server 24.04.4 LTS guest
- Oracle VirtualBox
- RAM 3.8 GB
- Disk 25 GB
